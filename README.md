# A Travel Log App

A full-stack app built with Nuxt that allows users to keep track of all the places they visited...

## Setup

Make sure to install dependencies: I'm using pnpm

```bash

# pnpm
pnpm install

```

## Development Server

Start the development server on `http://localhost:3000`:

```bash

# pnpm
pnpm dev

```

## Production

Build the application for production:

```bash

# pnpm
pnpm build

```

Locally preview production build:

```bash

# pnpm
pnpm preview

```
